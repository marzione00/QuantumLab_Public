# Quantum Lab

**Laboratorio interattivo autonomo · Topological Manifolds · edizione 5.1**

Sette moduli e 87 attività: fenomeni fisici, matematica, circuiti, algoritmi e protocolli quantistici. Percorso guidato, esplorazione e calcoli restano coordinati. Le 81 attività originali e i motori scientifici sono conservati; sei attività native aggiungono percorsi guidati.

La repository si pubblica con GitHub Pages e viene collegata dalla Didattica del sito principale, senza installatori, iframe o build condivise. L’atmosfera Matrix introduce codice a scorrimento, sfere di Bloch e onde ai lati; è decorativa, arrestabile e separata dai simulatori.

**Per iniziare: [INIZIA_QUI.md](INIZIA_QUI.md).**

```sh
npm test
npm run build
npm start
```

Node 22+, nessuna dipendenza di installazione per la build ordinaria. I test browser e scientifici storici hanno strumenti facoltativi propri: vedere [Collaudo](docs/COLLAUDO.md). La build `dist/` non contiene PDF, font, cache o manuali generati.
