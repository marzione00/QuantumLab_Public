# Topological Manifolds · Quantum Lab 5.0 RC1

Leggere **INIZIA_QUI.md**. L'applicazione funziona autonomamente; l'integrazione nel sito è un innesto reversibile, non una copia ricostruita del sito v3.3.

- Build senza dipendenze: `npm run build`.
- Controlli ordinari: `npm run check`.
- Regressione storica facoltativa: `npm run test:legacy`.
- Browser: `npm run test:browser`.
- Integrazione: `node integration/install.mjs /percorso/sorgenti-sito`.

Nessuna slide modificata, nessun deploy eseguito. L'originale completo del sito non era disponibile per il collaudo end-to-end. Versione italiana, candidata a revisione editoriale e accessibilità.
